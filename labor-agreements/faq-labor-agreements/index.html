    Labor Agreements FAQ in Omne RH Payroll¶

    Answers to common questions about working with labor agreements in Omne RH Payroll.

    What happens to voluntary improvements when I apply a revision?¶

    If the perception scheme line has the Agreement Change flag disabled, the system respects it and does not overwrite it. If the flag is active, the amount updates to the agreement value and the improvement is lost. Always verify the flag before each bulk application.

    What is the difference between Category and Salary Level in agreement lines?¶

    • With Category: The line applies exclusively to that specific professional category.
    • Without Category (by Salary Level): The line applies to all categories that share that salary level.

    When applying the agreement, the system processes category-level lines first (high priority) and salary-level lines second (low priority). If a concept is defined in both, the category-level line takes precedence.

    How is the part-time factor calculated?¶

    The factor is: Contract weekly hours / Agreement weekly hours.

    It applies automatically when transferring the salary table to the perception scheme of an employee whose contract has fewer hours than the agreement. If either hours value is zero, the factor is not applied, which may produce incorrect results.

    Can I use formulas and fixed amounts in the same agreement?¶

    Yes. Each line uses one of three mutually exclusive valuation methods:

    Method When to use
    Amount For concepts with a known fixed value (base salary, fixed bonuses)
    Calculation formula For concepts whose amount depends on other concepts or on annual working hours
    Coefficient For concepts whose amount is a factor over another value (requires a category)

    Formulas use tokens: salary concept codes (resolved to the concept amount in the scheme) and #1 (annual working hours from Payroll Config).

    Can I undo a replication with the wrong factor?¶

    There is no automatic undo. Your options are:

    1. Manually delete the lines of the new application date and replicate again with the correct factor.
    2. Replicate again from the original table with the correct factor (creates another date).
    3. Manually modify the amounts in the replicated table.

    The original salary table is never affected by replication.

    How do guaranteed salary parameters interact between agreement and company config?¶

    The hierarchy is: Agreement overrides Company Configuration. The guaranteed salary IT and AT fields in the agreement override the Company Configuration defaults for employees assigned to that agreement.

    Why do lines disappear when I change the application date?¶

    The agreement card works as a multi-validity document. The lines subpage only shows data for the selected application date. Changing the date navigates between different salary tables. If the selected date has no lines, the subpage appears empty. Use the Agreement Dates action to see which dates have salary tables.

    Blocked category vs. deleting a category: when to use each?¶

    Action Effect When to use
    Blocked = Yes The category does not appear in lookups but continues to exist. Historical employee records keep their reference When the category should not be assigned to new employees but historical records reference it
    Delete Permanently removed. Fails if records reference it Only if no record (employee, agreement line, historical entry) uses it
