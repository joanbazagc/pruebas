    Void Payrolls in Batch in Omne RH Payroll¶

    When a widespread error affects multiple payrolls in the same period (for example, incorrect contribution limits), void all affected payrolls at once instead of voiding them individually.

    Prerequisites¶

    • The payrolls must not be posted or paid.
    • Identify the period and employees affected.

    Steps¶

    1. Choose the search icon, enter "Void Payrolls Batch", and choose the related link.
    2. In the request page, set the filters:
    3. Period: the affected month
    4. Operation Type: Payroll
    5. Optionally filter by contribution unit or employee range
    6. Choose OK.
    7. Confirm the batch voiding when prompted.
    8. The system voids all payrolls matching the filters and reverses associated employee ledger entries.
    9. Correct the underlying data (update contribution limits, fix configuration, etc.).
    10. Recalculate the payrolls in batch.

    Result¶

    All payrolls for the selected period are voided. Employee ledger entries are reversed. Employees are available for recalculation.

    Common errors¶

    Error message Solution
    Cannot void posted payrolls Reverse the accounting entries first
