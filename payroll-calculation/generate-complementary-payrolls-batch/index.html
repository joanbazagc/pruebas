    Generate Complementary Payrolls in Batch in Omne RH Payroll¶

    Use this procedure to regularize social security contribution bases across several months at once, when an extra pay period requires retroactive adjustments — for example, after a change to which salary concepts are subject to contribution for extra pay. Unlike calculating a single complementary payroll for back pay, this process creates the perception scheme lines, calculates each month's complementary payroll, and moves the employee's social security contribution to the settlement month automatically, in a single run.

    Prerequisites¶

    • The extra pay period (Extra bonus bussiness) has the Calculate initial date and End calculate date fields set.
    • The complementary scheme code is empty, or you accept deleting its existing lines when prompted.
    • The complementary scheme code is not assigned to any contribution unit.
    • If Source payroll type is Monthly, the Prorated price conc. Code field is set (a deduction-type salary concept that receives the employee's contribution in the monthly payroll). This field is not required when the source type is Complementary.
    • Monthly payrolls (or prior complementary payrolls, depending on the source type) are already calculated for the period covered by the extra pay.

    Steps¶

    1. Choose the search icon, enter "Massive complementary generation", and choose the related link.
    2. Fill in the options:
    3. Liquidation date: the target settlement period date.
    4. Source payroll type: Monthly to prorate from the ordinary monthly payroll, or Complementary to prorate from a prior complementary payroll.
    5. Complementary Scheme Code: the scheme code to create or reuse.
    6. Prorated price conc. Code: required when Source payroll type is Monthly.
    7. Enable the phases to run: Create schemes, Calculate complementary, Generate TC's RED.
    8. On the Extra bonus bussiness filter tab, filter by Payment number.
    9. Optionally, filter by Employee No. on the payroll lines filter tab to limit the process to specific employees.
    10. Choose OK.

    Result¶

    The process runs in phases automatically: it creates perception scheme lines prorated by employee and month, calculates each month's complementary payroll (keeping only social security contribution bases, with no earnings or income tax lines), and adds a deduction line to the settlement month's monthly payroll for the total employee contribution moved from the complementary payrolls. If enabled, RED TC2 files are also generated for each month in the period.

    Common errors¶

    Error message Solution
    "You must enter Complementary Scheme Code and settlement date." Fill in the Complementary Scheme Code and Liquidation date fields
    "You must enter a value in field Prorated price conc. Code to calculate complementary payroll." Set the Prorated price conc. Code field when Source payroll type is Monthly
    "Error. You cannot use a Scheme Code assigned in a Quote Unit!" Use a Complementary Scheme Code that is not already assigned to a contribution unit
