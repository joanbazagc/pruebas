    Troubleshooting Income Tax Issues in Omne RH Payroll¶

    Error when choosing "Change all" or "Change marked"¶

    Symptom: The system shows an error and does not apply any changes.

    Cause: The system requires the cursor to be on a line with the Year field filled in.

    Solution: Position the cursor on any line that has the Year field filled and choose the action again.

    Proposed percentage is 0% for an employee with salary¶

    Symptom: After choosing "Calculate proposal", some employees show proposed % = 0.

    Cause: One of the following:

    • The employee's net income (after reductions and minimums) is below the taxable minimum
    • Form 145 data is not filled in, resulting in no applicable reductions
    • Retention tables for the year and corresponding tax authority are not loaded

    Solution:

    1. If salary is low: this is a correct result (exempt from withholding).
    2. If Form 145 data is missing: fill it in and recalculate.
    3. If retention tables are not loaded: load them before recalculating.

    Cannot generate the electronic file for model 111¶

    Symptom: When trying to generate the electronic file, the system shows an error.

    Cause: The tax administration does not have the tax domicile configured, which is required for electronic file generation.

    Solution:

    1. Choose the search icon, enter "Administraciones Hacienda", and choose the related link.
    2. Locate the corresponding administration.
    3. Fill in the tax domicile field.
    4. Verify the settlement folders (monthly and/or quarterly).
    5. Try generating the file again.

    Unexpected confirmation when changing percentage for an employee with fixed rate¶

    Symptom: When applying "Change all" or "Change marked", the system shows a confirmation dialog for certain employees.

    Cause: The employee has a fixed percentage requested via Form 145. The system asks for confirmation because there is a discrepancy between the fixed and proposed rates.

    Solution: Respond to the dialog based on your criteria:

    • Yes: The percentage changes and the fixed mark is removed.
    • No: The current fixed percentage is maintained.

    Cannot mark both pre-2011 and post-2011 mortgage simultaneously¶

    Symptom: When trying to mark one mortgage option while the other is already marked, the system shows an error.

    Cause: Both fields are mutually exclusive. Tax regulations distinguish between mortgages constituted before and after 2011 with different deduction regimes.

    Solution: Unmark one field before marking the other. Select the one that corresponds to the actual mortgage constitution date.

    NIF validation error when registering Form 145 data¶

    Symptom: When entering the spouse NIF or employee document, the system shows a validation error.

    Cause: The NIF format is incorrect or the control letter is invalid.

    Solution: Enter the NIF in the correct format: 8 digits + control letter (for example, 12345678Z). For NIE: initial letter (X/Y/Z) + 7 digits + control letter.

    Settlement duplicates amounts when regenerating¶

    Symptom: After regenerating a settlement for the same period, amounts appear doubled.

    Cause: The settlement calculation was run without first canceling the previous settlement for the same period.

    Solution:

    1. Cancel the duplicate settlement.
    2. Verify that only one correct settlement remains for the period.
    3. If needed, cancel all settlements for the period and regenerate once.

    Employees missing from model 190 annual summary¶

    Symptom: When generating model 190, the file does not contain some employee records.

    Cause: One of the following:

    • Payrolls were not calculated for all months of the fiscal year
    • Income tax journal entries were not posted (still in draft)
    • Employees have incorrect or empty perception keys

    Solution:

    1. Calculate any pending payrolls.
    2. Post pending income tax journal entries.
    3. Verify and correct perception keys in the IRPF employee table.
