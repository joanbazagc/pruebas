    Set Up Bizneo Integration in Omne RH Payroll¶

    Before you use Bizneo, configure the connection, the integration modes, and the employee transfer behavior.

    Prerequisites¶

    • The Bizneo API URL and token are available.
    • You have access to the Bizneo site configuration.
    • Employee transfer rules are defined for the company.
    • The employee master data is complete enough to be synchronized.

    Step 1: Configure the Bizneo site connection¶

    1. Choose the search icon, enter "Sites" or "Telematic Sites", and choose the related link used in your environment.
    2. Find the record for Bizneo.
    3. Enter the API URL and the authentication token provided by Bizneo.
    4. Save the record.

    Step 2: Configure portal integration modes¶

    1. Choose the search icon, enter "Portal Integration Settings", and choose the related link.
    2. Create the Bizneo configuration if it does not already exist.
    3. Set the provider to BizneoHCM or BizneoATS depending on the use case.
    4. Set the data type to Portal Employee, Absences, or Selection as needed.
    5. Choose the integration mode for output and input.
    6. Mark the configuration as active.

    Step 3: Decide how employees will enter Bizneo¶

    The preferred method is to transfer payroll employees into Employee Integrations from the payroll employee list.

    Option Result
    Transfer from payroll employee list Keeps the payroll link and sets the integration metadata correctly
    Create the integrated employee manually Only use this when the person does not yet exist as a payroll employee

    Step 4: Verify the setup¶

    1. Confirm that at least one active Bizneo configuration exists.
    2. Confirm that the Bizneo site record contains a valid URL and token.
    3. Confirm that employees can be transferred into Employee Integrations.
    4. Confirm that the integration log records each execution.
