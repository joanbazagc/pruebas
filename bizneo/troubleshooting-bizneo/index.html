    Troubleshooting Bizneo Integration in Omne RH Payroll¶

    An employee is not sent to Bizneo¶

    If the employee does not reach Bizneo, check these items:

    1. The employee is marked for portal integration.
    2. The Bizneo configuration is active.
    3. The integration mode allows outbound synchronization.
    4. The employee has the required name, document, company, and email data.

    Authentication fails¶

    If the integration returns an authentication error, verify the Bizneo URL and token in the Bizneo site configuration.

    The employee comes back from Bizneo but the payroll record looks incomplete¶

    The import must complete the payroll employee and its auxiliary records. If it stops early, review the integration log and rerun the import from Employee Integrations.

    Contracts do not keep their Bizneo identifier¶

    Check that the contract has a start date and belongs to the same employee record that Bizneo returned. If multiple contracts share the same start date, only the first matching record may be updated automatically.

    Documents do not appear in Bizneo¶

    Check that the document is linked to a valid employee, has an attached file, and was sent from the HR documents area or the employee integration actions.

    When to escalate to support¶

    Escalate the issue when:

    • The token is correct but Bizneo still returns HTTP 401 or 403.
    • The same document or employee fails repeatedly after cleanup.
    • The integration log shows a server-side Bizneo error that does not clear after retry.
