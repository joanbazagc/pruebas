    Set Up Sick Leave and Incidents in Omne RH Payroll¶

    Before you can register sick leave or any other work interruption, you must configure the incident codes, contribution rates, and auxiliary tables.

    Prerequisites¶

    • Employees registered with their Social Security affiliation number (NAF)
    • Active contracts with configured working hours
    • At least one contribution unit with the main contribution account (CCC)
    • Work accident mutual assigned to the contribution unit

    Configure incident codes¶

    Incident codes define the types of leave or absence available in the system.

    1. Choose the search icon, enter "Incident Codes", and choose the related link.
    2. Create a new record for each incident type you need:
    3. Enter a Code (for example: ENF, ACC, MAT, HUE).
    4. Enter a Description of the incident type.
    5. Select the Incident category from the dropdown.
    6. Complete the configuration fields based on the type:
    Incident type Key fields to configure
    Illness Special IT situation (if applicable), Contingency code, Benefit code, Company improvement code
    Accident Contingency code, Benefit code, Company improvement code
    Maternity Contingency code, Benefit code
    Absenteeism Deduct salary, Absence cause code
    Paid leave Absence cause code
    Unpaid leave Deduct salary = Yes, No worker contribution = Yes
    Strike Deduct salary = Yes
    ERE SEPE benefit/subsidy cause code, Deduct ERE benefit

    Configure accident contribution rates¶

    Contribution rates define the AT/EP (work accident and occupational disease) percentages by economic activity.

    1. Choose the search icon, enter "Accident Contribution Rates", and choose the related link.
    2. For each rate, configure:
    3. Code: Internal identifier
    4. Description: Economic activity description
    5. IT: IT contribution rate (percentage with 3 decimals)
    6. IMS: IMS contribution rate (percentage with 3 decimals)
    7. Accident contribution rate: Official Social Security code
    8. The Total field is calculated automatically (IT + IMS).

    For contribution rate 114, you must also set the Secondary rate field. The system calculates types as 30% of the secondary rate, with minimums of 0.63% for IT and 0.36% for IMS.

    Verify contribution unit configuration¶

    Before generating RED files, confirm each contribution unit has:

    • The main contribution account (11-digit format)
    • The AT/EP mutual assigned
    • The correct legislation code

    Load Social Security auxiliary tables¶

    The following tables should be loaded in the system:

    Table Content
    Contingencies IT contingency types (1=Common illness, 2=Non-work accident, 3=Work accident, 4=Occupational disease)
    Discharge causes Medical discharge reasons (Cure, Permanent disability proposal, Death)
    IT process types Expected duration (Very short, Short, Medium, Long)
    Report types RED communication codes (PB=Sick report, PA=Discharge report, PC=Confirmation)
    Maternity rest types Maternity modalities
    Inactivity RED inactivity codes per table T-41

    These tables are typically preloaded during installation. Verify them by choosing the search icon and entering "S.S. Tables".

    Verification checklist¶

    Before registering incidents, confirm:

    • At least one incident code exists for each type (Illness, Accident, Maternity)
    • Accident contribution rates are configured for your economic activities
    • Contribution units have the contribution account and mutual set up
    • Social Security auxiliary tables are loaded
    • Employees have their affiliation number (NAF) entered
    • At least one employee has an active contract for testing
