    Sick Leave FAQ in Omne RH Payroll¶

    Frequently asked questions about managing sick leave and incidents in Omne RH Payroll.

    What is the difference between Start Date and Original Start Date?¶

    Start Date is the effective start of the incident, which may include the days charged to the company (typically the first 3 days of leave that the company covers). Original Start Date is the date from the physician's sick leave report. In most cases they match, but for work accidents or professional contingencies they may differ.

    How do I know if an incident has been communicated to Social Security?¶

    Check the RED Notification Count field in the incidents list. If the number is greater than zero, at least one RED report has been created for that incident. To see the details of generated reports, choose the RED Data Query action from the Siltra group.

    Can I modify an incident after generating the FDI file?¶

    Yes, you can modify incident data at any time. However, if the FDI file was already sent through SILTRA, you must generate a new file with the corrections and send it again. Social Security processes the last file received for each incident.

    You cannot modify incidents in periods where a payroll has already been calculated. In that case, void the corresponding payroll first.

    What is a relapse and how is it registered?¶

    A relapse occurs when an employee goes on sick leave again for the same cause of a previous incident that was already closed. To register it, create a new incident with the same code, set the Relapse field to Yes, and select the original incident in the Relapse Incident Code field. The system calculates accumulated days automatically.

    What are economic data in the RED context?¶

    Economic data (DE report) is a complementary communication to the sick leave report that includes the employee contribution bases. Social Security may request them to calculate the benefit. Create them from the incidents list using the Siltra group and choosing Create Econ. Data RED.

    What is the difference between an accident with leave and without leave?¶

    • With leave: The accident causes medical leave. An individual accident report is generated and sent to the mutual via the Delta system. A RED report is also created for Social Security.
    • Without leave: The accident does not require medical leave but must still be registered. These accidents are accumulated in a monthly consolidated report submitted periodically to the mutual.

    Can I register incidents for multiple employees at once?¶

    Yes, use the Bulk Incidents function from the Process action group in the incidents list. This is useful for strikes or ERE affecting multiple employees simultaneously. You can filter by contribution unit or other criteria to select affected employees.

    What does the Unalterable Values field mean?¶

    When you activate Unalterable Values in an incident, the system will not recalculate economic data (contribution bases, days contributed, and so on) in subsequent processes like payroll calculation. Use this when you have manually adjusted values and do not want them overwritten.

    How do I send incidents to the attendance control system?¶

    Select the incident in the list and choose Send to AC from the Attendance Control action group. The incident is transmitted to the attendance control module and reflected automatically in the employee timesheets for the affected period.
