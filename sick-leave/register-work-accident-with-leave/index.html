    Register a Work Accident With Medical Leave in Omne RH Payroll¶

    When an employee suffers a work accident that requires medical leave, you must register the incident, complete the accident details, and generate the Delta report for the mutual insurance company.

    Prerequisites¶

    • An incident code configured with the Accident type exists
    • The employee card has phone number and job position entered

    Steps¶

    1. Choose the search icon, enter "Incidents", and choose the related link.
    2. Create a new incident:
    3. In Incident Code, select the accident code (for example, ACC).
    4. In Start Date, enter the accident date.
    5. Leave End Date empty (the leave is still open).
    6. From the action group Delta, choose Create Accident.
    7. The accident details card opens.
    8. Complete the required accident fields:

    General section: - Accident Date: Date the accident occurred. - Time of Day: Hour (0-24 format). - Work Hour: Which hour of the work shift (for example, 2 for the second hour). - Accident Description: Detailed description of what happened. - Professional Situation: Select the applicable option. - Was Habitual Work: Yes or No.

    Accident location section: - Accident Location: Habitual center, In-journey travel, Commuting, or Other center. - Traffic: Yes or No (if it was a traffic accident).

    Accident classification section (select from Social Security tables): - Location Code, Work Type Code - Physical Activity Code and Physical Activity Material Agent - Deviation Code and Deviation Material Agent - Injury Form Code and Injury Causing Material Agent

    Medical data section: - Injury Code and Body Part Injured - Injury Severity: Minor, Serious, Very serious, or Death. - Hospitalized: Yes or No. - Healthcare Facility Type: Hospital or Outpatient.

    Preventive modality: Mark at least one option (or mark None).

    1. Choose the Validate Data action to confirm all required fields are filled.
    2. Choose Accident Report With Leave to generate the report file for the mutual.

    Result¶

    The work accident is registered with full details and the Delta report is generated for submission to the mutual insurance company.
