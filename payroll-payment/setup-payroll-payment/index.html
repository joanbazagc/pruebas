    Set Up Payroll Payment in Omne RH Payroll¶

    Before you can process payroll payments, you must configure the bank catalog, verify employee bank data, and optionally set up interest rates for loans.

    Prerequisites¶

    • Employees must be registered with complete bank data (IBAN)
    • Payrolls for the period must be calculated and posted
    • The bank catalog must include SWIFT codes for SEPA file generation

    Set up the bank catalog¶

    Banks are required to generate SEPA transfer files.

    1. Choose the search icon, enter "Banks", and choose Banks (Payroll).
    2. For each bank, fill in the following fields:
    3. Code: A 4-character bank identifier (for example, 0049).
    4. Bank Name: The full name of the financial institution.
    5. SWIFT Code: The BIC code of the bank (required for SEPA files).

    [!IMPORTANT] The SWIFT Code field is mandatory for SEPA file generation. Without it, the bank will reject the file.

    Verify employee bank accounts¶

    Each employee must have a bank assigned with a complete IBAN.

    1. Choose the search icon, enter "Employees (Payroll)", and choose the related link.
    2. Select the employee, then choose Employee Bank.
    3. Verify that:
    4. The IBAN field is complete (ES format + 22 digits).
    5. The CCC (Account Code) is correct.
    6. The bank is linked to a code from the bank catalog.

    Set up interest rates (loans only)¶

    If your company grants employee loans, configure the applicable interest rates.

    1. Choose the search icon, enter "Interest rate", and choose Interest Rate and Money Value.
    2. Fill in the fields:
    3. Start Date: The date from which the rate applies.
    4. Interest %: The annual interest percentage.
    5. Money Value %: The money value percentage.
    6. Interest Concept Code: Automatically filled from Company Setup.
    7. Money Value Concept Code: Automatically filled from Company Setup.

    Configure default deduction settings (loans only)¶

    If your company manages loans or advances, configure default values in Company Setup.

    1. Choose the search icon, enter "Company Setup", and choose the related link.
    2. Verify that Accrue Money Value and Calculate Interest are enabled if you want new deductions to inherit these values automatically.

    Verification checklist¶

    After completing the setup, verify:

    • The bank catalog has at least one entry with a SWIFT code.
    • Main employees have a bank assigned with a valid IBAN.
    • Payrolls for the period are calculated.
    • (If using loans) Interest rate is configured with a current start date.
    • (If using CRETA) Contribution units have an assigned bank.

    Quick test¶

    1. Choose the search icon, enter "Prepare Payment", and choose the related link.
    2. Select a date range for the current period.
    3. The system should display payroll records pending payment.
    4. If no records appear, verify that payrolls are calculated and that entries have a Pending status.
