    Payroll Payment FAQ in Omne RH Payroll¶

    Common questions and answers about the payroll payment process in Omne RH.

    What is the difference between Post and Post and Transfer?¶

    When posting the payroll journal, the system presents two options:

    • Post: Only confirms the payments in the system. You must generate the bank file manually afterward.
    • Post and Transfer: Confirms the payments and automatically opens the bank file generation page. This is the fastest option if you plan to submit transfers immediately.

    Use Post and Transfer unless you need to review payments before generating the file.

    Which bank file format should I choose: SEPA, N34, or N34-1?¶

    Format When to use
    SEPA Recommended for most current banks. European standard XML format.
    N34 Only if your bank specifically requires it. Classic Spanish text format.
    N34-1 If you need international transfers in the classic format.

    If you are unsure, check with your financial institution. Most Spanish banks have accepted SEPA for years.

    What happens if an employee has partial payment across multiple banks?¶

    The system handles this automatically. When an employee has partial payment configured:

    • The payment preparation generates multiple lines for the same employee, one per bank.
    • The amount is distributed according to the employee bank percentage configuration.
    • Each line carries its own destination bank.

    No manual intervention is required.

    Can I modify journal lines before posting?¶

    Yes. After running Prepare Payroll Payment and before choosing Post, you can:

    • Correct amounts.
    • Change the destination bank.
    • Delete lines that should not be paid this month.
    • Add lines manually.

    Changes are preserved until you post the journal.

    How do I know which payrolls are pending payment?¶

    Payrolls pending payment are those with a Pending status. You can check this in two ways:

    1. From the Role Center: KPI indicators show the number of pending payrolls and active employees for the period.
    2. From Prepare Payment: The preparation process only includes pending entries with a non-zero amount.

    If no records appear when preparing payments, all payrolls have already been paid, or no payrolls have been calculated for that period.

    How does the automatic percentage recalculation work in deductions?¶

    When an employee has multiple periodic deduction lines with the same code:

    1. Lines with Fixed Percentage enabled keep their percentage unchanged.
    2. The remaining lines share the remaining percentage equally.
    3. The system calculates: % per line = (100% - total fixed %) / total number of payments.

    This recalculation runs automatically when you modify the Number of Payments or Discount % in any line.

    What is the difference between Bank Transfer File and Create Transfer File?¶

    Aspect Bank Transfer File Create Transfer File
    Generates printed list Yes No
    Supports UTF-8 No Yes
    Output format ZIP (file + list) Direct file
    Typical use File + audit report Only the bank file needed

    Use Create Transfer File if your bank rejects the file due to special characters, as it supports UTF-8 encoding.

    Can I cancel a posted payment?¶

    Yes. Use Cancel Payments (choose the search icon, enter "Cancel Payments"):

    • The system reverses the payment application against payroll entries.
    • Payment entries are deleted.
    • Affected payrolls return to Pending status.

    If the payment was already posted to accounting, you must also reverse the accounting entry.

    What is CRETA and when do I need it?¶

    CRETA is the electronic communication system with the Spanish Social Security (TGSS). The module generates SLD (Bank Data) files to:

    • Communicate the bank assigned to each contribution unit.
    • Report bank changes.
    • Request deletion of bank assignments.

    You need it when you register a new contribution unit, change a bank for a contribution unit, or when the TGSS requests bank data confirmation.
