    Troubleshooting Payroll Payment in Omne RH Payroll¶

    Solutions for common problems encountered when processing payroll payments in Omne RH.

    "There is nothing to register" when posting the journal¶

    Cause: The payroll journal has no payment lines.

    Solution:

    1. Verify you are in the correct journal book and section.
    2. Run Prepare Payroll Payment first (choose the search icon, enter "Prepare Payroll Payment").
    3. If you already ran it and still see no lines, verify that payrolls are calculated for the selected period.

    "Cannot contain a filter when posting a periodic journal"¶

    Cause: A periodic journal does not allow date filters to be active during posting.

    Solution:

    1. Remove all active filters from the journal, especially Posting Date filters.
    2. Choose the filter icon and clear all filters.
    3. Try posting again.

    Bank rejects the SEPA file¶

    Cause: The most common reasons are invalid IBAN, missing SWIFT code, or unsupported special characters.

    Solution by cause:

    Invalid IBAN or missing SWIFT¶

    1. Choose the search icon, enter "Banks (Payroll)", and verify the bank has a SWIFT Code.
    2. Open the affected employee card, choose Employee Bank, and verify the IBAN is complete.
    3. Regenerate the file.

    Special characters¶

    1. Instead of Bank Transfer File, use Create Transfer File (choose the search icon, enter "Create Transfer File").
    2. On the Options tab, select Encoding: UTF-8.
    3. Generate the file again.

    "Inconsistency in the type of discounts" in periodic deductions¶

    Cause: Certain deduction types cannot coexist in the same deduction code.

    Incompatible combinations:

    If a line exists with You cannot add
    All Months and Extra Pays Another All Months and Extra Pays, All Months, or All Extra Pays
    All Months Another All Months or All Months and Extra Pays
    All Extra Pays Another All Extra Pays or All Months and Extra Pays
    Month (specific) Another line with the same month
    Extra Pay (specific) Another line with the same extra pay

    Solution:

    1. Review all existing lines for the deduction.
    2. Delete or modify the conflicting line.
    3. If you need specific months, use the Month type with a specific month on each line.

    Discount percentages change unexpectedly in deductions¶

    Cause: This is expected behavior. The system automatically redistributes percentages so they total 100%.

    How it works:

    • Lines with Fixed Percentage enabled are not modified.
    • Remaining lines share the leftover percentage equally.

    Solution:

    • To prevent a percentage from changing, enable Fixed Percentage on that line before entering the value.
    • If you only need to specify the number of payments, let the system calculate the percentage automatically.

    "Prepare Payment" generates no lines¶

    Cause: No payrolls with Pending status exist for the selected period.

    Solution:

    1. Broaden your filters: clear the Document Type filter and expand the date range.
    2. Verify that payrolls are calculated for the period by checking the payroll ledger.
    3. Check that payments have not already been posted. Previously paid payrolls are no longer in Pending status.

    "Renaming the blank code is not allowed" when editing a deduction¶

    Cause: The blank-code record is a special system record that cannot be renamed.

    Solution:

    1. Do not attempt to rename this record.
    2. Create a new deduction with the desired code instead.
    3. Configure the required data on the new record.
    4. Reassign references in the affected employees.
