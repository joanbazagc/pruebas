    Configure an Employee Loan in Omne RH Payroll¶

    When a company grants a loan to an employee, you can configure a deduction that automatically discounts a fixed amount from their payroll each month, with optional interest calculation.

    Prerequisites¶

    • The employee must be registered in the system.
    • A discount salary concept must be configured for loans.
    • (Optional) Interest rates must be set up if the loan accrues interest.

    Create the deduction¶

    1. Choose the search icon, enter "Deductions", and choose Deductions (Payroll).
    2. Choose New to create a record.
    3. Fill in the fields:
    4. Code: An identifier for this deduction (for example, LOAN001).
    5. Description: A description (for example, Employee loan).
    6. Employee No.: Select the employee.
    7. Discount Concept: Select the salary concept for the discount.
    8. No Limit: Clear this checkbox (the loan has a fixed amount).
    9. Payment Method: Select Bank Transfer if repaid via transfer.
    10. If the loan accrues interest:
    11. Enable Accrue Money Value.
    12. Enable Calculate Interest.
    13. Choose Save.

    Configure periodic deduction¶

    1. From the deductions list, select the deduction you just created.
    2. Choose the Periodic Ded. action in the action bar.
    3. On the Periodic Deductions page, fill in:
    4. Deduction Type: Select All Months (discounted every month).
    5. Period Amount: Enter the monthly repayment amount (for example, 200).
    6. Number of Payments: Enter the total repayment months (for example, 12).
    7. Discount %: Calculated automatically when you enter the number of payments.
    8. Choose Save.

    Result¶

    • The deduction is linked to the employee.
    • Each monthly payroll automatically deducts the configured amount.
    • The system calculates interest based on the current rate if interest is enabled.

    Important notes¶

    • The Discount % field automatically recalculates when you modify the Number of Payments in any line. This is expected behavior.
    • Lines with Fixed Percentage enabled keep their percentage unchanged during recalculation.
    • If you see the error "Inconsistency in the type of discounts", you cannot mix certain deduction types in the same code. Review existing lines for conflicts.
