    Generate a SEPA Bank File in Omne RH Payroll¶

    After posting payroll payments, generate a bank transfer file to submit payment orders to your financial institution. Omne RH supports SEPA (XML), N34, and N34-1 formats.

    Prerequisites¶

    • Payments must be posted in the payroll journal.
    • Banks in the catalog must have a valid SWIFT Code (for SEPA format).
    • Employees must have valid IBAN numbers.

    Generate the bank file¶

    1. Choose the search icon, enter "Bank Transfer File", and choose the related link.
    2. On the filter page, set:
    3. Document No.: The range of payment documents to include.
    4. Document Type: Filter by Payment and/or Withholding Deposit.
    5. On the Options tab, set:
    6. Standard: Select SEPA (recommended for most current banks). Alternatively, select N34 or N34-1 for legacy formats.
    7. Choose OK.

    The system generates a compressed ZIP file containing the bank file in the selected format and a printed list of included transfers.

    Choose the right format¶

    Format When to use
    SEPA Recommended for most current banks. European standard XML format.
    N34 Only if your bank specifically requires it. Classic Spanish text format.
    N34-1 If you need to include international transfers in the classic format.

    Alternative: Create Transfer File (UTF-8)¶

    If your bank rejects the file due to special characters, use the alternative report:

    1. Choose the search icon, enter "Create Transfer File", and choose the related link.
    2. On the Options tab, select Encoding: UTF-8.
    3. Choose OK.

    This option generates the file directly without a printed list but supports full UTF-8 encoding.

    Common errors¶

    Issue Solution
    Bank rejects file (invalid IBAN) Verify all employees have a valid IBAN in their bank setup
    Bank rejects file (missing SWIFT) Add the SWIFT code to the bank in Banks (Payroll)
    Special character rejection Use Create Transfer File with UTF-8 encoding instead
