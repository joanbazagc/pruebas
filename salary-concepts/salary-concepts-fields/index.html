    Salary Concepts Field Reference in Omne RH Payroll¶

    The Salary Concepts page is an editable list (no separate card page). To open it, choose the search icon, enter "Salary Concepts", and choose the related link.

    Identification fields¶

    Field Description
    Code Unique identifier for the concept (up to 10 characters). Part of the primary key
    Concept Type Nature of the concept: Earning, Deduction, Bases, Text, or Cost. Part of the primary key
    System Concept Indicates whether the concept is predefined by the system (cannot be deleted)
    Description Descriptive name (up to 30 characters)

    Social security and contribution fields¶

    Field Description
    SS Code Official social security code for the concept
    SS Description Description of the SS code (read-only, calculated)
    Subject to Contribution Whether the concept contributes monthly to social security
    Additional Contribution Differentiated contribution type (for example, overtime)
    Contribute on Proration Prorated contribution when earned. Requires Variable = Yes and Subject to Contribution = No

    Tax fields¶

    Field Description
    Perception Key Determines the fiscal treatment. Inherits IRPF Exempt and In Kind values
    IRPF Exempt Whether the concept is exempt from income tax withholding (read-only, inherited)
    In Kind Whether the concept is a benefit in kind (read-only, inherited)
    Income on Account The company assumes the income tax on account
    Company Income on Account Concept Auxiliary concept for income on account
    % IPREM Excess Percentage of excess over the IPREM indicator

    Payroll behavior fields¶

    Field Description
    Subconcept Detailed classification: INSS Benefit, Worker Quota, IRPF Withholding, Overtime, Pension Plans, etc.
    Guaranteed Salary Part of the guaranteed salary for sick leave or work accident
    Variable Amount changes each month
    Include in Gross Included in the gross base calculation
    Excluded Part Time Excluded from part-time contract adjustments
    Quantity Management Controls quantity behavior: empty, Excluded Part Time, or Bypass Formula Quantity
    To Indemnify Included in indemnification calculations
    Prorate Prorated by days worked
    Periodicity Greater than Month Periodicity longer than one month (extra pays)
    Extra Pay No. Linked extra pay
    Non-Retroactive Excluded from retroactive calculations
    Provision if in Scheme Generates provision only if the concept exists in the perception scheme
    Discard Simulation Excluded from simulation payrolls
    Compose Hour Cost Included in hour-cost calculation
    Provision Provisioning mode: empty, Variable, or Without De-provision. Requires Extra Pay No.
    Formula Months in Extra Pays Reference months for the extra pay formula
    Vacation Treatment Special treatment: No Treatment, Discount Vacation, or Do Not Discount Vacation Own Price

    Garnishment fields¶

    Field Description
    Garnishable Garnishment level: According to SMI, Fully, or Not Garnishable
    Do Not Garnish Exclude from garnishments (synchronized with Garnishable)

    Flexible remuneration fields¶

    Field Description
    Flexible Remuneration Whether the concept is part of a flexible remuneration plan
    In Kind Deduction Concept Linked deduction concept for in-kind remuneration
    Exemption Limit Code Fiscal exemption limit for flexible remuneration
    Limit Excess Concept Concept that captures the excess over the exemption limit
    Flexible Remuneration Deduction Concept Linked deduction concept for the flexible plan

    Accounting and printing fields¶

    Field Description
    Concept Accounting Group Accounting group defining expense and liability ledger accounts
    Print Description Whether the description prints on the payslip
    Payslip Print Row Vertical position on the payslip
    Payslip Print Column Horizontal position on the payslip
    External Code Code for external system integration

    Available actions¶

    Action Group Description
    Apply Changes Process Propagates changes to all perception schemes and labor agreement lines
    Load Garnishable Field Process Mass-updates garnishment settings across all concepts
    Translations — Opens translations for the selected concept
    Update Payroll Lines — Updates garnishment in historical payroll lines
