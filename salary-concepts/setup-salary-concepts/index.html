    Set Up Salary Concepts in Omne RH Payroll¶

    Before creating salary concepts, verify that the required master data is configured. Then create concepts with identification, tax, contribution, payroll, and accounting properties.

    Prerequisites¶

    Requirement Where to verify
    Perception keys defined Choose the search icon, enter "Perception Keys", and choose the related link
    Contribution types configured Choose the search icon, enter "Contribution Types", and choose the related link
    Concept accounting groups created Choose the search icon, enter "Salary Concept Accounting Group", and choose the related link
    Extra pays defined Choose the search icon, enter "Company Extra Pays", and choose the related link
    INEM tables (SS codes) Choose the search icon, enter "INEM Tables", and choose the related link

    Steps¶

    1. Choose the search icon, enter "Salary Concepts", and choose the related link.
    2. The page is an editable list (there is no separate card page).
    3. Create a new line and fill in the minimum required fields:
    4. Code: Unique identifier (up to 10 characters), for example SB.
    5. Concept Type: Select the nature of the concept: Earning, Deduction, Bases, Text, or Cost.
    6. Description: Descriptive name, for example Base salary.
    7. Set the Subject to Contribution field to Yes if the concept contributes to social security.
    8. Assign a Concept Accounting Group for ledger integration, for example SALARIOS.

    Configure tax properties¶

    Tax properties are managed through the Perception Key field:

    1. In the concept line, select a value in the Perception Key field.
    2. The system automatically inherits the IRPF Exempt and In Kind values from the perception key master.
    3. These inherited fields are read-only on the concept. To change them, modify the perception key or assign a different one.

    Configure contribution properties¶

    • Subject to Contribution: Set to Yes for concepts that contribute monthly to social security.
    • Additional Contribution: Specify a contribution type if the concept has a differentiated rate (for example, overtime).
    • Contribute on Proration: For variable concepts that contribute proportionally when earned (requires Variable = Yes and Subject to Contribution = No).

    Configure payroll behavior¶

    • Subconcept: Detailed classification (INSS benefit, Worker quota, IRPF withholding, etc.).
    • Variable: For concepts whose amount changes each month.
    • Prorate: For concepts prorated by days worked.
    • Periodicity Greater than Month: For concepts such as extra pays.
    • Extra Pay No.: Link to a specific extra pay.
    • Garnishable: Garnishment level (According to SMI, Fully, or Not garnishable).

    Verification¶

    After creating the basic concepts, confirm:

    • Each concept has a code, type, and description.
    • Concepts with special tax treatment have a Perception Key assigned.
    • Contributing concepts have Subject to Contribution = Yes or Additional Contribution specified.
    • Each concept has an accounting group assigned.
    • Text and Cost type concepts do not contribute and are not taxed (informational only).
