    Troubleshooting Employees (Payroll) in Omne RH Payroll¶

    NIF/NIE check digit is incorrect¶

    Symptom: When you enter the identification document, the system shows an error and does not allow saving.

    Cause: The NIF or NIE number contains a typo, or the control letter does not match the calculated check digit.

    Solution:

    1. Verify the document number against the worker's original document.
    2. Correct the number or control letter as indicated by the system message.
    3. If the document type is Passport, the system does not validate a check digit.

    Employee already exists with the same document or NAF¶

    Symptom: When registering a new employee or changing NIF/NAF, a message indicates another employee already has the same document.

    Cause: You are registering an employee with a NIF or NAF that belongs to another record.

    Solution:

    1. Check whether the worker is already registered under a different employee number.
    2. If it is an unintended duplicate, correct the NIF or NAF.
    3. If it is a legitimate situation (for example, rehiring), confirm the duplicate when prompted.
    4. To enable or disable duplicate control, go to Company Setup and check the Do not control repeated employees field.

    Cannot change the NAF because payrolls exist¶

    Symptom: When you try to change the affiliation number, the system blocks the modification.

    Cause: The employee has calculated payrolls with the current NAF. The system blocks changes to maintain Social Security file consistency.

    Solution:

    1. If few payrolls exist, consult technical support about canceling payrolls, correcting the NAF, and recalculating.
    2. If the NAF change is legitimate (new affiliation number), it may be necessary to terminate the current employee and create a new one with the correct NAF.
    3. Contact technical support for the recommended approach.

    Missing mandatory data (additional data, income tax, banks, or contract)¶

    Symptom: The Errors field on the Employee Card shows messages about missing data blocks.

    Cause: The employee was registered but not all mandatory data blocks were completed.

    Solution:

    1. Open the Employee Card.
    2. Choose the Creation Wizard action.
    3. The wizard opens each incomplete data block sequentially: complementary data, income tax, banks, and contract.
    4. Complete all requested data in each page.
    5. Verify the Errors field is empty when finished.

    Work permit is expiring or has expired¶

    Symptom: Validation shows a warning about work permit validity for a foreign worker.

    Cause: The work authorization expiry date is within 15 days or has already passed.

    Solution:

    1. Open the employee's Complementary Data (from the card, choose the Complementary Data action).
    2. In the Foreign Workers section, check the Work Authorization Validity field.
    3. If the permit has been renewed, update the date with the new validity.
    4. If not renewed, coordinate renewal with the appropriate department.

    Income tax family situation is inconsistent with dependents¶

    Symptom: Validation shows an error that the family situation "Unmarried with children" is inconsistent with dependent records.

    Cause: The family situation is set to "Unmarried with children" but no qualifying dependent (child under 25 without income or with disability) is registered.

    Solution:

    1. Open the employee's Dependents (from the card, choose the Dependents action).
    2. Verify at least one dependent is registered as a qualifying child.
    3. If the family situation is incorrect, change it in the income tax data.

    Only one bank with payment type Resto is allowed¶

    Symptom: Validation shows an error that multiple banks have the "Resto" payment type.

    Cause: Two or more bank accounts are configured with the "Resto" (main payment) type. Only one is allowed.

    Solution:

    1. Open Employee Banks from the Employee Card.
    2. Identify accounts with payment type "Resto."
    3. Change the type of extra accounts to another type, or remove unused accounts.
    4. Keep only one account with type "Resto."

    When to contact technical support¶

    Contact support if:

    • You need to change the NAF for an employee with calculated payrolls.
    • Validation errors cannot be resolved with available data.
    • You need to delete an employee that has associated payrolls.
    • There are integration issues with the employee portal or attendance control.
    • Inconsistencies exist between employee data and official Social Security files.
