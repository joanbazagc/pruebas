    FAQ for Employees (Payroll) in Omne RH Payroll¶

    How do I know if an employee has all mandatory data filled in?¶

    Open the Employee Card. At the bottom, the Errors field shows the first detected problem in red. Choose the field to see the full error list. If the field is empty, all minimum required data is filled in.

    You can also run bulk validation from the Employee List using the Validate Employees action.

    Can I change the affiliation number (NAF) for an employee who has payrolls?¶

    No. The system blocks NAF changes for employees with calculated payrolls to prevent inconsistencies in Social Security files. Contact technical support if you need to correct an incorrect NAF.

    What is the difference between the Employee Card and Complementary Data?¶

    The Employee Card contains essential payroll data: identification, address, hiring, income tax, and accounting. The Complementary Data page extends the record with personal details (date of birth, marital status, disability), alternative payment data, foreign worker permits, and settings for the employee portal and attendance control.

    Access Complementary Data from the Employee Card using the Complementary Data action.

    What does the creation wizard do?¶

    The creation wizard opens four pages sequentially to complete mandatory data for a new employee:

    1. Complementary Data — Creates the record and opens the page if it does not exist or is incomplete.
    2. Income Tax Data — Creates an initial tax record and opens the page if it does not exist.
    3. Employee Banks — Opens the bank list if no account with payment type "Resto" exists.
    4. Contract — Creates an initial contract and opens the card if none exists.

    You can run the wizard at any time from the Employee Card using the Creation Wizard action.

    Can I have two employees with the same NIF?¶

    Yes, but the system asks for explicit confirmation. When you register an employee with a NIF that already exists for another employee, a message informs you of the existing record. If your organization has disabled duplicate control in Company Setup, this validation does not run.

    How do I change the income tax percentage?¶

    Open the Employee Card. In the P.I.T. section, change the Income Tax % field. If there is a tax history, the system asks for confirmation and resets historical values. Enable Fixed Income Tax % if the rate should not be recalculated automatically.

    What does it mean when "Calculate Payroll" is disabled?¶

    If the Calculate Payroll field is disabled, the employee is excluded from payroll calculation processes. This can happen because the associated contribution regime excludes them automatically, or because it was set manually. The employee still exists in the system but does not generate payrolls.
