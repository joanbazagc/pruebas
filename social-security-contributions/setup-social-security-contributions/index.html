    Set Up Social Security Contributions in Omne RH Payroll¶

    Before processing social security contributions, you must configure the annual tables that define minimum and maximum bases, national calculation caps, contribution rates, and AT/EP tariffs.

    Prerequisites¶

    • Company Setup module configured with contribution units (CCC) and CNAE codes.
    • Employees registered with their social security regime and contribution group.
    • Active contracts with contract type and social security occupation codes.
    • Access to the official Social Security tables for the current fiscal year.

    Configure contribution bases¶

    1. Choose the search icon, enter "Contribution Bases", and choose the related link.
    2. Verify that records exist for the current fiscal year.
    3. If no records exist, create one for each combination of regime and group (01 to 11):
    4. Regime Code: Social security regime (General, SEA, Domestic Workers, Artists).
    5. Contribution Group: Group 01 to 11 based on professional category.
    6. Year: Current fiscal year.
    7. Contribution M/D: Monthly (groups 01-07) or Daily (groups 08-11).
    8. Minimum Base and Maximum Base: Values from official tables.
    9. Min. Base/Hour Part-Time: Minimum base per hour for part-time contracts.

    Configure calculation caps¶

    1. Choose the search icon, enter "Calculation Caps", and choose the related link.
    2. Create or update a record for the current year with:
    3. Monthly SMI and Daily SMI: Current minimum wage values.
    4. Monthly IPREM and Daily IPREM: Public income indicator values.
    5. Max. Cap AT/EP Over 18 and Min. Cap AT/EP Over 18: AT/EP limits.

    Configure contribution rates¶

    1. Choose the search icon, enter "Contribution Rates", and choose the related link.
    2. Verify records exist for all required codes: CC, DESEMP, FOGASA, FP, MEI, and ATEP.
    3. For each rate, specify:
    4. Employer %: Percentage charged to the employer.
    5. Employee %: Percentage charged to the employee.
    6. Application Base: Which base to apply (Contribution Base, AT/EP Base, Overtime Base).

    Configure AT/EP tariffs¶

    1. Choose the search icon, enter "AT/EP Contribution Rates", and choose the related link.
    2. Verify that tariffs exist for your company's CNAE code:
    3. Filter by Element = "CNAE Activities".
    4. Locate the CNAE code configured in the company's contribution unit.
    5. Enter the IT % (temporary disability) and IMS % (invalidity, death, survival) percentages.

    Activate the CRETA system¶

    1. Choose the search icon, enter "Payroll Setup", and choose the related link.
    2. Set the Contribution System field to:
    3. Practice: Generates segments for testing without sending to Social Security.
    4. Real: Generates segments and files for actual submission.

    Configure allowances (optional)¶

    1. Choose the search icon, enter "Allowances", and choose the related link.
    2. Create records with: allowance code, description, reduction percentage, duration in months, and the CRETA special circumstance code (B01 to B06).

    Result¶

    The system is ready to calculate social security contributions. When payroll is calculated, contribution segments are generated automatically based on these tables.
