    Troubleshooting Social Security Contributions in Omne RH Payroll¶

    Common problems and solutions for social security contribution processing.

    Payroll shows "No contribution bases found"¶

    The system cannot find contribution bases for the employee's regime, group, and year combination.

    Solution¶

    1. Choose the search icon, enter "Contribution Bases", and choose the related link.
    2. Filter by Year = current fiscal year.
    3. Verify that a record exists for the exact combination of:
    4. The employee's Regime Code.
    5. The active contract's Contribution Group.
    6. The payroll period's Year.
    7. If a record is missing, create it with the official values from the BOE.

    Contribution base below minimum and CRETA rejects it¶

    The calculated CC base is less than the group minimum. This can occur with part-time contracts with few hours or mid-month hires/terminations.

    Solution¶

    1. If the contract is part-time: verify that the Min. Base/Hour Part-Time field is filled in for the relevant group in Contribution Bases.
    2. If the contract is full-time with a mid-month start or end: verify the contract dates to ensure the days contributed are correct.
    3. Recalculate the payroll after the correction.

    Contributions not calculated for a specific code (FOGASA, MEI, etc.)¶

    Contribution lines for a specific code appear empty or zero in the payroll.

    Solution¶

    1. Choose the search icon, enter "Contribution Rates", and choose the related link.
    2. Filter by Year = current year and Regime Code = employee's regime.
    3. Look for the missing Code (CC, DESEMP, FOGASA, FP, MEI, ATEP).
    4. If no record exists, create one with the official percentages and the correct Application Base.
    5. Recalculate the affected payrolls.

    CRETA segments with Error status after FAN import¶

    After importing the FAN file, some segments show Error status, meaning internal data does not match Social Security records.

    Solution¶

    1. Compare critical fields between internal segments and FAN data:
    2. NAF (affiliation number), Start Date, End Date, Contribution Group, Contract Type, SS Occupation Code.
    3. Identify which field differs.
    4. Correct the source data:
    5. Wrong group: Update in the employee's contract.
    6. Wrong dates: Review in the Social Security Affiliation module.
    7. Wrong occupation: Update in the contract.
    8. Recalculate the payroll for the period to regenerate segments.
    9. Re-import the FAN file to verify the correction.

    Segments with Surplus status (exist in ERP but not in Social Security)¶

    Internal segments have no match in Social Security data after FAN validation.

    Solution¶

    1. Verify whether the employee's hire was communicated to Social Security.
    2. Check the Social Security Affiliation module for pending affiliation actions.
    3. Once the hire is communicated and processed, download an updated FAN file and re-import.
    4. The segments should change to Validated status.

    CRETA file rejected for XML format¶

    The generated IDC file is immediately rejected by Sistema RED without processing.

    Solution¶

    1. Verify there are no invalid special characters in worker data (names with non-standard characters).
    2. Verify the CCC (contribution account code) is exactly 11 characters in Company Setup.
    3. Verify the period format is correct (YYYYMM).
    4. Verify the settlement type is valid (L00, L02, or L03).
    5. Regenerate the file after corrections.

    Allowance assigned but not applied in payroll¶

    An allowance is assigned in the employee card but the employer contribution does not reflect the reduction.

    Solution¶

    1. Verify the allowance dates cover the payroll period (Start Date is on or before the period and End Date is on or after).
    2. Verify the allowance duration has not expired.
    3. Check for incompatible allowances assigned to the same employee (only one applies).
    4. Verify the Special Circumstance Code (B01-B06) is filled in the allowances master table.
    5. Recalculate the payroll.

    No contribution segments generated after payroll calculation¶

    Payroll calculates but no CRETA segments are created.

    Solution¶

    1. Choose the search icon, enter "Payroll Setup", and choose the related link.
    2. Check the Contribution System field.
    3. If set to No, change it to Practice (for testing) or Real (for production).
    4. Recalculate the payrolls for the period. Segments will now be generated.
