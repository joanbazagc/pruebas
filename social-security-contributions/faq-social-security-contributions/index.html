    FAQ Social Security Contributions in Omne RH Payroll¶

    Answers to common questions about social security contributions, CRETA segments, and related configuration.

    What is the difference between Contribution Base and AT/EP Base?¶

    The Contribution Base (Common Contingencies base) is calculated from monthly pay plus extra pay proration, with minimum and maximum limits per contribution group. The AT/EP Base (Work Accidents and Professional Illness) starts from the same pay but also includes overtime hours, and uses different national caps from the Calculation Caps table.

    Each contribution rate is linked to a specific base through the Application Base field. For example, Common Contingencies (CC) uses the Contribution Base, while AT/EP uses the AT/EP Base.

    What happens if a contribution rate is missing for a required code?¶

    If the system cannot find a contribution rate for a mandatory code (such as MEI or FOGASA), the corresponding contribution line will not be calculated. The payroll completes without a blocking error, but the contribution lines for that code will be empty. The CRETA file will be incomplete and rejected by Social Security.

    To fix this, choose the search icon, enter "Contribution Rates", and create the missing record with the official percentages.

    Do the extended fields overwrite the original values?¶

    No. Extended fields (Extended Minimum Base, Extended Monthly SMI, etc.) coexist with the original values. The system selects which to use based on the payroll period date:

    • Periods before the extended date: Original values are used.
    • Periods on or after the extended date: Extended values are used.

    This allows recalculating payrolls for earlier months without the new values interfering.

    How does the system determine if a CRETA segment is Internal or SS type?¶

    Internal segments are generated by the payroll calculation in the ERP. SS segments are imported from the Social Security FAN file. Comparing both detects discrepancies:

    • An Internal segment without a FAN match receives status Surplus (possibly an unreported hire).
    • An SS segment without an internal match indicates data that Social Security has but the ERP does not.

    When should I use a Supplementary vs. Out-of-Term settlement?¶

    Type Code When to use
    Normal L00 First settlement of the period
    Supplementary L02, L03 To correct a previously submitted settlement (differences only)
    Out-of-Term — For periods submitted after the deadline set by Social Security

    Use Supplementary when you detect errors after sending L00. Use Out-of-Term when no settlement was filed within the legal deadline.

    Is the 75% allowance for workers over 62 on sick leave assigned manually?¶

    No. The system calculates it automatically. When a worker over 62 has a common contingencies sick leave incident, the segment calculation detects the condition and automatically assigns the B06 special circumstance code with a 75% allowance. No manual assignment is needed.

    For other allowances (B01 young workers, B02 under 30, B03 over 45), manual or bulk assignment is required.

    Does the Application Base field distinguish between normal and force majeure overtime?¶

    Yes. The available values include both Overtime Base (normal overtime) and Non-Structural Overtime Base. This ensures each contribution rate is applied to the correct base, since force majeure overtime has a reduced contribution rate compared to normal overtime.

    What is the difference between segment period types?¶

    Period Type When used
    Contracted Normal active work period
    Holidays Paid untaken holidays (typically after termination or sick leave)
    Deferred Termination Period after termination where contributions are still due for deferred wages

    Changes in period type within the same month generate separate segments.
