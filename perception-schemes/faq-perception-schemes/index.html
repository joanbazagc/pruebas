    Perception Schemes FAQ in Omne RH Payroll¶

    What is the difference between the Amount and Variable Amount fields?¶

    The Amount field contains the fixed monthly value of a concept (for example, a base salary of 1,800.00 that does not change). When a concept is marked as Variable, the Variable Amount and Variable Quantity fields appear, allowing you to register values that change monthly through the perception journal, without modifying the fixed base amount.

    A concept can have both a fixed amount and a variable amount simultaneously. Payroll calculation uses both according to the concept rules.

    What happens if I copy a scheme and the target already exists?¶

    The system shows a confirmation dialog. If you confirm, the target scheme is completely deleted (all lines and the key) and replaced with the lines from the source scheme. Amounts are copied as-is. If there is a salary revision, you must update amounts manually or use the Salary Variation action.

    The Last Existing option in the copy dialog automatically selects the latest application date from the source scheme.

    How does the Sporadic option affect payroll calculation?¶

    A scheme with Sporadic enabled is not included in batch payroll calculation runs. It is only processed when you run individual calculation from the scheme card using the Post Payroll (F9) action.

    This is useful for supplementary or termination schemes that are calculated on demand and should not interfere with regular monthly payroll.

    What is the difference between a Gross advance and a Net advance?¶

    Type Calculation Tax regularization
    Gross The amount is advanced as-is, without deductions Not triggered
    Net Net = Gross minus social security minus income tax Automatic

    A net advance requires that all lines in the same posting belong to the same period (month). If there are lines from different months, you must post them separately.

    What does the Agreement Change flag mean on scheme lines?¶

    When a line has Agreement Change set to Yes, that line is not automatically updated when you run agreement change or salary variation processes. It is marked automatically when a user manually customizes an amount that originally came from the labor agreement.

    This is a protection mechanism: if an employee has an individual arrangement for a concept that differs from the agreement table, this flag prevents a bulk agreement update from overwriting that arrangement.

    How does automatic variable grouping in the journal work?¶

    If the Sum Var. Perception Journal option is enabled in company setup, the system automatically groups journal lines with the same salary concept before posting to the scheme. For example, if there are three lines for "Commissions" with amounts of 100, 200, and 150, a single line with amount 450 is posted.

    If disabled, each line is processed individually and may trigger the Replace/Add dialog for duplicates.

    Can an employee have multiple schemes?¶

    Yes. An employee can have multiple schemes with different combinations of header, agreement, and date. A typical setup includes: - A Monthly scheme for regular payroll - An Extra Pay scheme for extraordinary payments - Optionally, Supplementary schemes for arrears or regularizations

    Each scheme has its own key identified by employee + scheme + agreement + application date.

    How is the Annual Amount on a line calculated?¶

    It depends on the Calculation Key assigned to the line:

    Key Formula
    MONTHLY Amount x 12
    DN (Natural days) Amount x 365
    DT (Working days) Amount x 247
    No key Amount without multiplier

    The annual amount recalculates automatically whenever the line amount is modified. The sum of annual amounts for Earning-type concepts is shown in the header as Annual Gross Amount.
