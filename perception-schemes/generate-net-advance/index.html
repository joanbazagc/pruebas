    Generate a Net Advance in Omne RH Payroll¶

    You can advance part of an employee's pay before the regular payroll calculation. A net advance automatically deducts social security contributions and income tax withholding from the gross amount, and regularizes the tax withholding percentage.

    Prerequisites¶

    • The employee's scheme is configured with the concepts that will generate the advance.
    • A deduction code for advances is configured.
    • A payroll journal book and section are configured to receive the advance entry.

    Steps¶

    1. Choose the search icon, enter "Perception Journal Sections", and choose the related link. Then choose Edit Journal.
    2. Locate or create the line for the concept to advance.
    3. Set the Advance field to Yes.
    4. Select the advance type:
    5. Net: Deducts social security and income tax. Triggers automatic tax regularization.
    6. Gross: Advances the full amount without deductions.
    7. Fill in the required fields:
    8. Advance Deduction Code: The deduction code for the advance.
    9. Payroll Journal Book: The target journal book.
    10. Payroll Journal Section: The target journal section.
    11. Posting Date: The date for the accounting entry.
    12. Choose Post Journal (F9).
    13. The system performs two internal steps:
    14. Posts the line and marks it for income tax regularization.
    15. Regularizes the income tax and generates the advance with the calculated net amount.

    Result¶

    The advance is posted to the payroll journal with the net calculated amount. The employee's income tax withholding percentage is automatically regularized. The line is removed from the perception journal.

    Tips¶

    • If you receive the error "You must inform the deduction code of the advance", fill in the Advance Deduction Code field before posting.
    • If you receive "You must report the book and section of the payroll journal", fill in both journal book and section fields.
    • If you receive "Error, cannot be anticipated to net. There are 2 different periods", post advances from different months in separate operations.
