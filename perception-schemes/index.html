    Perception Schemes Overview in Omne RH Payroll¶

    Perception schemes define the individualized salary structure for each employee in payroll. A scheme groups the salary concepts (earnings, deductions, bases, costs) that determine how payroll is calculated, including fixed amounts, monthly variables, and automatic calculation formulas.

    Key concepts¶

    Scheme header¶

    A scheme header is a template that defines the payroll type. Each header specifies whether the scheme applies to monthly payroll, extra pay, advances, or supplementary pay.

    Payroll type Purpose
    Monthly Regular monthly payroll
    Extra Pay Extraordinary payments (June, December, etc.)
    Advances Payroll advances
    Supplementary Arrears, regularizations, etc.

    Scheme key¶

    A scheme key links an employee to a specific scheme, labor agreement, and application date. This combination allows multiple versions of a scheme over time, for example when amounts are updated due to an agreement revision.

    Scheme line¶

    Each line represents a salary concept within the scheme. It contains the amount or calculation formula, concept type (earning, deduction, base, text, cost), and properties affecting social security contributions, income tax, proration, and monthly variability.

    Perception journal¶

    A temporary worksheet for bulk entry of variable perceptions. It collects variable concepts from multiple employees, allows editing of period amounts, and posts them in bulk to their respective schemes.

    Variable perceptions¶

    Salary concepts with amounts that change every month (commissions, overtime, variable bonuses). The "Variable" flag on a scheme line enables the concept to be collected in the perception journal for periodic updates.

    Calculation formulas¶

    Expressions that reference other concepts within the same scheme to calculate amounts automatically. The system uses an internal engine that processes inter-concept expressions, so that changing one field recalculates dependent formulas.

    Who uses this module¶

    Role Main use
    Payroll technician Configure and maintain schemes, register monthly variable perceptions, manage advances
    HR manager Review salary structure, check annual gross amounts
    Functional consultant Configure scheme templates by agreement, automate salary variations

    How it relates to other modules¶

    • Labor agreements provide categories and available concepts to the scheme
    • Employees are individually assigned to schemes
    • Salary concepts define the concepts referenced in scheme lines
    • Payroll calculation uses scheme lines as the calculation basis
    • Income tax (IRPF) handles regularization after net advances
    • Payroll accounting uses the accounting group from each concept line
