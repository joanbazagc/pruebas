    Troubleshoot Social Security Files in Omne RH Payroll¶

    TC2 file does not include some employees¶

    Possible causes¶

    • The employee does not have a posted payroll for the period.
    • The payroll has the Excluded from Contribution field marked.
    • The employee is not assigned to the filtered contribution unit.
    • The employee's contribution regime does not match the filter.

    Resolution¶

    1. Choose the search icon, enter "Payroll Headers", and verify the employee has a payroll for the period.
    2. If the payroll exists, check the Excluded from Contribution field and unmark it if the employee should contribute.
    3. Verify the employee's contribution unit and regime assignment match the filters used.

    Error receiving CRETA files — Directory not found¶

    Possible causes¶

    • The directory path does not exist or is misspelled.
    • The user does not have read permissions on the folder.
    • The telematic site configuration is incorrect.

    Resolution¶

    1. Verify the path exists in the file system.
    2. Check folder permissions for the Business Central service account.
    3. Choose the search icon, enter "Telematic Sites", and verify the site code and directory path match.

    CRETA segments show Error status with code I001¶

    Possible causes¶

    • Recent employee registrations do not yet have internal segments.
    • Data migration was incomplete.
    • The period or start date does not match exactly.

    Resolution¶

    1. Choose the search icon, enter "Contribution Segments", and filter by Status = "Error" and Code = "I001".
    2. For each segment, verify if an internal segment exists with the same CCC, NAF, and start date.
    3. If it does not exist, create the internal segment manually.
    4. Re-run validation.

    CRA file shows negative amounts¶

    Possible causes¶

    • Complementary payrolls with negative retroactive adjustments.
    • Returns or regularizations exceed the positive amount for the period.
    • Payroll calculation errors.

    Resolution¶

    1. Run the CRA Concepts List report to identify affected concepts.
    2. Review payrolls for the period for those concepts.
    3. Either correct the payroll, generate a complementary liquidation, or defer to the next period if the negative is correct.

    FLC form connection error¶

    Possible causes¶

    • The FLC telematic site is not configured or the API Key has expired.
    • Network connectivity to the TGSS service is unavailable.
    • Required data on the contribution unit is incomplete.

    Resolution¶

    1. Choose the search icon, enter "Telematic Sites", and verify the FLC site has a valid API Key and URL.
    2. Test network connectivity to the service URL.
    3. Verify the contribution unit has CCC, CIF, and period data filled.
    4. If the TGSS service is under maintenance, retry later.

    ERTE/ERE certificate generates empty¶

    Possible causes¶

    • No qualifying incidents exist for the filtered employees.
    • Incident types are not recognized (must be ERE, illness, accident, maternity, or vacation).
    • The company filter is incorrect.
    • For termination prior transmission, contracts lack the Termination Cause Code.

    Resolution¶

    1. Choose the search icon, enter "Incidents", and verify records exist for the employees.
    2. Check that incident types match the expected categories.
    3. For termination ERE, verify contracts have the termination cause code filled.
    4. Broaden filters if they are too restrictive (for example, remove the employee filter).

    Affiliation records not updated after batch file generation¶

    Possible causes¶

    • The process was interrupted before completing the update.
    • No records matched the filter criteria.

    Resolution¶

    1. Verify that records have the Send Date filled and Sent Date empty.
    2. Re-run the process. The system generates a new file without creating duplicate data in the affiliation records.
