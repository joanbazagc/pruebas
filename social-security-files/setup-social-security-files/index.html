    Set Up Social Security Files in Omne RH Payroll¶

    Before generating social security files, you must configure master data, telematic sites, and verify that payrolls are correctly calculated and posted.

    Prerequisites¶

    • Companies must be configured with tax ID (CIF) and contribution account codes (CCC).
    • Employees must have a Social Security Affiliation Number (NAF) assigned.
    • Contribution units must be created and assigned to employees.
    • Active contribution regimes must exist with the No Contribution field unmarked.
    • Payrolls for the period must be calculated and posted.

    Step 1: Verify company setup¶

    1. Choose the search icon, enter "Company Setup", and choose the related link.
    2. For each company, verify the following fields are filled:
    3. Name: Company name
    4. CIF: Tax identification code
    5. CCC: Social Security contribution account(s)
    6. Choose Save.

    Step 2: Verify contribution regimes¶

    1. Choose the search icon, enter "Regime Control", and choose the related link.
    2. Verify that active regimes have:
    3. Contribution Regime: The regime code (for example, 0111 for General Regime)
    4. No Contribution: Unmarked (must be FALSE for the regime to generate files)
    5. Choose Save.

    Step 3: Configure telematic sites¶

    For systems requiring electronic communication (CRETA, SILTRA, FLC):

    1. Choose the search icon, enter "Telematic Sites", and choose the related link.
    2. For each site, configure:
    3. Site Code: System identifier (for example, SILTRA, CRETA, FLC)
    4. Directory Path: Folder path for sending and receiving files
    5. Credentials: API Key or certificates as required by the system
    6. Choose Save.

    Step 4: Verify salary concepts for CRA¶

    If you plan to generate CRA files (Compensation Paid Communication):

    1. Choose the search icon, enter "Salary Concepts", and choose the related link.
    2. Verify that each concept has the SS Code field filled with the Social Security classification code.
    3. Concepts without an SS Code are excluded from the CRA file.

    Step 5: Configure affiliation for RED files¶

    If you plan to generate RED affiliation files:

    1. Choose the search icon, enter "Affiliation", and choose the related link.
    2. Verify that records pending submission have:
    3. Send Date: Planned submission date
    4. Order No.: Record order number
    5. Records that already have a Sent Date value are excluded (already submitted).

    Configuration checklist¶

    # Verification
    1 Companies configured with CIF and CCC
    2 Contribution regimes active (No Contribution = FALSE)
    3 Contribution units assigned to employees
    4 Telematic sites configured (if applicable)
    5 Salary concepts with SS Code (if using CRA)
    6 Payrolls calculated and posted for the period
    7 User permissions in OMNEPayroll area
