    Contracts Overview in Omne RH Payroll¶

    The Contracts module in Omne RH Payroll manages the complete lifecycle of employment contracts: creation, maintenance, extensions, termination, and integration with external systems such as SEPE (NetContrata) and the Social Security RED System.

    Key concepts¶

    • Contract key: A 3-character code that identifies the contract type according to current legislation (for example, "100" for permanent ordinary, "401" for temporary work or service). Each key defines legal conditions such as minimum and maximum duration, social security contribution rates, and whether the contract qualifies for subsidies.

    • Extension (Prórroga): A renewal of a temporary contract. Each extension creates a new linked record with its own start date, duration, and end date. The system validates that total duration does not exceed the legal maximum for the contract type.

    • Subsidy (Bonificación): A reduction of employer social security contributions linked to the employee's group (age, disability, unemployed status) and the contract type. Subsidies can have time-based tiers with different percentages.

    • Substitution: A contract created to cover the temporary absence of another worker (sick leave, maternity, leave of absence). The substitute contract records the replaced employee and the substitution cause.

    • Successive contract: A chain of contracts for the same employee where each contract starts the day after the previous one ends. The system detects these automatically to calculate seniority correctly.

    What you can do¶

    • Create and manage employment contracts with automatic validation of legal limits
    • Extend temporary contracts with duration validation
    • Terminate contracts with automatic calculation of pending vacation days
    • Process bulk contract changes from Excel files
    • Assign and manage employer subsidies
    • Generate AFI movements for Social Security communication
    • Register contracts and extensions with SEPE via NetContrata
    • Run reports for contract listings, upcoming expirations, and substitutions
