    Contracts FAQ in Omne RH Payroll¶

    What is the difference between Terminated and Company Leave?¶

    Company Leave is a date field indicating when the worker left the company. When you fill this field, the system automatically sets Terminated = Yes. However, Terminated can also be set when an extension is finalized and propagates its status to the base contract.

    Key difference: - Company Leave with a date means the worker has ceased employment and pending vacation days are calculated - Terminated without Company Leave means the contract was closed administratively (the worker may have another active contract)

    To generate an AFI leave movement, both Company Leave and Leave Cause Code must be filled.

    Can I change the contract key after creating extensions?¶

    No. Once a contract has linked extensions, the system blocks modification of the Contract Key field because extensions inherit duration rules from the original contract type.

    To change the contract key: 1. Delete all extensions in reverse order (last to first) 2. Modify the Contract Key 3. Recreate extensions if still needed

    How does the system handle garnishments with successive contracts?¶

    When a new contract starts the day after the previous one ends (successive contract), the system does not automatically intervene with garnishments. If there is a gap between contracts, the system detects pending withholding movements from the prior contract and offers to carry them forward to the new contract.

    What happens with vacation when a temporary contract lasts less than 11 months?¶

    The Prorated Vacation field activates automatically for temporary contracts shorter than 11 months. In these cases, vacation is calculated proportionally to time worked and included as a severance concept at termination, rather than taken as time off.

    How is seniority calculated with successive contracts?¶

    When the system detects a chain of successive contracts (same employee, same contract key, each starting the day after the previous ends), it traces back to the original contract. Seniority is calculated from the start date of that first contract.

    This affects: - Pending vacation day calculations - Seniority-based pay supplements - Severance compensation rights

    Can I delete a contract that has calculated payrolls?¶

    No. The system prevents deletion of contracts when calculated payrolls exist for the employee in the contract period. You must cancel all associated payrolls before deleting the contract.

    The same restriction applies to modifying the Start Date or End Date when payrolls exist in the affected dates.

    What do the Integrated Contracts statuses mean?¶

    Status Meaning Action
    Pending Generated but not yet sent to the external system Verify data and trigger the send
    Sent Successfully sent to the external system None needed
    Send Error An error occurred during send or processing Review contract data, correct, and retry

    The Integrated Contracts page is read-only. Corrections must be made on the original contract and resent.

    How does the Subsidy Group Code affect subsidies?¶

    The subsidy group code classifies the worker by characteristics (age, sex, disability degree, unemployed status) to determine the applicable subsidy. The system cross-validates: - If the group requires a minimum age, it checks against the employee's birth date - If it requires a specific sex, it checks the employee's sex - If it requires a disability degree, it verifies the registered degree

    An incompatible group code generates a validation error when saving.
