    Troubleshooting Contracts in Omne RH Payroll¶

    Cannot modify the contract key¶

    Symptom: The system shows an error or blocks editing the Contract Key field.

    Cause: The contract has linked extensions. The system blocks this change to maintain duration validation consistency.

    Solution: 1. Open the extensions list for the contract (choose Extensions from the contract). 2. Delete extensions in reverse order (last to first). 3. Return to the contract card and modify the Contract Key. 4. Recreate extensions if needed.

    Cannot create an extension - "This contract cannot be extended"¶

    Symptom: The system displays an error when trying to create an extension.

    Cause: Either the contract is marked as Terminated = Yes, or it is already marked as Extended = Yes.

    Solution: - If Terminated = Yes: the contract is closed. Create a new contract instead. - If Extended = Yes: an extension already exists. Create the next extension from the most recent extended contract, not the original.

    Extension duration exceeds maximum¶

    Symptom: The system shows an error about exceeding maximum time when entering an extension duration.

    Cause: The extension end date exceeds the Maximum Time defined in the contract type, calculated from the start date of the first contract in the series.

    Solution: 1. Check the Start Date of the first contract in the employee's series for that key. 2. Look up the Maximum Time in the contract types catalog. 3. Calculate the maximum allowed date: first contract start date + maximum time. 4. Adjust the extension duration so the end date stays within this limit. 5. If the worker must continue beyond the maximum, consider converting to a permanent contract.

    Online Office (NetContrata) actions are not visible¶

    Symptom: The contracts list does not show the Online Office action group.

    Cause: The NetContrata integration is not configured or not active.

    Solution: 1. Choose the search icon, enter "OMNE NetContrata Config", and choose the related link. 2. Verify a configuration record exists. 3. Confirm the integration is marked as active. 4. Verify credentials and connection endpoint. 5. Close and reopen the contracts list.

    Cannot generate AFI leave - missing required data¶

    Symptom: The system shows an error when choosing Create AFI Leave.

    Cause: The Company Leave field or Leave Cause Code field is empty.

    Solution: 1. Open the contract card. 2. Fill in the Company Leave field with the leave date. 3. Fill in the Leave Cause Code field. 4. Choose Save. 5. Return to the contracts list and retry Create AFI Leave.

    Print model not found when printing a contract¶

    Symptom: The system shows an error that no print model is available.

    Cause: No print model is assigned for the contract type, document type (CONTRACT or ANNEX), and optionally the employee's language.

    Solution: 1. Choose the search icon, enter "Contract Types", and choose the related link. 2. Select the contract type that failed. 3. Choose Print Models from the action bar. 4. Verify at least one model of type CONTRACT exists. 5. If missing, create one and link a valid report.

    Cannot delete a contract - payrolls exist¶

    Symptom: The system shows an error about existing calculated payrolls when trying to delete.

    Cause: Calculated payrolls exist for the employee in the contract period.

    Solution: 1. Identify the calculated payrolls for the employee. 2. Cancel the payrolls from the Payroll Calculation module. 3. Retry the contract deletion.

    Note: Deleting a contract also removes associated substitutions, subsidies, perception schemes, and work calendar in cascade.

    Employee data not updated after contract modification¶

    Symptom: After modifying contract fields, the employee card does not reflect the changes.

    Cause: The contract-to-employee synchronization runs on the OnModify trigger. If modification was done externally or an error occurred, data may be out of sync.

    Solution: 1. Open the contract card. 2. Make a minor change (for example, modify and restore a field value). 3. Choose Save to force the OnModify trigger to execute. 4. Verify that employee data is now updated.

    Extensions cannot be deleted - order error¶

    Symptom: The system shows an error when trying to delete an extension.

    Cause: Extensions must be deleted in reverse order (last to first) to maintain date consistency.

    Solution: 1. Identify the last extension (highest Extension No.). 2. Delete it first. 3. Continue deleting from highest to lowest number until you reach the one to remove. 4. If you only need to close an extension without deleting it, set Extension Finalized = Yes instead.
