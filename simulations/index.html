    Payroll Simulations Overview in Omne RH Payroll¶

    The Simulations module lets HR managers and finance directors project workforce costs under hypothetical scenarios. You can model salary increases, new hires, headcount reductions, and salary concept changes without modifying actual payroll data.

    Key concepts¶

    • Scenario: A hypothesis for salary revision, identified by a code, fiscal year, and revision percentage.
    • Scenario lines: Rules that define what happens to each element (labor agreement category, employee, or salary concept) within the scenario.
    • Simulation results: The calculated monthly and annual costs per employee and salary concept after running a scenario.

    Available actions for scenario lines¶

    Action Description
    Apply Forecast Applies the scenario salary revision percentage
    Do Not Apply Forecast Keeps values unchanged (salary freeze)
    Discard Element Excludes the employee or category from the simulation
    Increment Element Simulates new hires (N copies of a category)
    Incident Simulates a leave (sick leave, maternity, etc.)

    General workflow¶

    1. Create a scenario with the target year and revision percentage.
    2. Configure exceptions (new employees, leaves, concept variations).
    3. Run the generation process.
    4. Review projected costs.
    5. Approve, discard, or adjust the scenario.

    Related modules¶

    • Employees (Payroll): Provides the employee base for calculations.
    • Contracts: Determines which employees are active in the simulated period.
    • Labor Agreements: Provides professional categories and salary tables.
    • Salary Concepts: Breaks down amounts by concept.
