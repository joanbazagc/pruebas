    Frequently Asked Questions About Payroll Simulations¶

    Can I have multiple scenarios for the same fiscal year?¶

    Yes. You can create as many scenarios as needed for the same year. This is the standard way of working: create several alternatives and compare them before making a decision.

    Do simulations modify real payroll data?¶

    No. Simulations work with completely separate tables. Employee records, contracts, and actual payroll data are never affected. You can create, delete, and regenerate simulations without any impact on regular payroll processes.

    What happens if I regenerate simulations for a scenario?¶

    When you run Create Simulations again, results are recalculated based on the current scenario configuration and active employee data. Previous results are overwritten. If you modified scenario lines after the first run, regenerating updates the amounts to reflect the changes.

    What is the difference between Salary Revision % and CPI %?¶

    • Salary Revision %: The percentage actually applied to amounts when the action is "Apply Forecast."
    • CPI %: An informational reference field to document the year's consumer price index. It is not applied automatically in calculations.

    The percentage that affects amounts is always the Salary Revision %.

    What is a Starting Scenario used for?¶

    Normally, the simulation starts from real payroll data (contracts, perception schemes). If you specify a Starting Scenario, calculations use that other scenario's results as a base instead of the real situation. This is useful for chaining scenarios. For example, first simulate a freeze (FREEZE2027), then create another scenario that starts from FREEZE2027 to add selective raises.

    How is the cost of a new hire calculated (Increment Element)?¶

    When Increment Element is set with a quantity of 3:

    • Three fictitious employees are created with the salary structure of the specified category.
    • If a Start Date is specified, the cost is prorated from that date to the end of the fiscal year.
    • If a Discard Date is specified, the cost is calculated only up to that date.

    For example, 3 new employees from March 1, 2027 means 10 months of cost (March to December).

    Can I simulate sick leave?¶

    Yes. In the employee-level configuration, you can set the action to Incident and select the type (Illness, Accident, Maternity, etc.). Enter a start date and optionally a duration. The calculation considers the cost reduction during the incident period.

    How do I know if a scenario has been executed?¶

    Open the Scenario Card and choose Simulation Overview. If the results page shows lines with amounts, the scenario has been executed. If it is empty, choose Create Simulations first.

    Can I delete a scenario?¶

    Yes. Deleting a scenario from the list also deletes all its configuration lines and simulation results. This action is irreversible. If the scenario has status Approved, consider changing it to Discarded first to maintain traceability.

    Are scenarios multi-company?¶

    Yes. The Create Simulations process supports multi-company. If the company filter is left empty, it calculates only for the current company. If multiple companies are specified, it calculates for all selected companies.
