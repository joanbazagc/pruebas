    Troubleshoot Payroll Simulations in Omne RH Payroll¶

    Missing calendar error when creating simulations¶

    Symptom¶

    When you choose Create Simulations, an error message indicates that the calendar is missing for the fiscal year.

    Cause¶

    The simulation process requires a payroll calendar for the scenario fiscal year. If the scenario targets 2027 but the calendar only exists through 2026, the calculation cannot determine working days.

    Resolution¶

    1. Choose the search icon, enter "Payroll Calendars", and choose the related link.
    2. Verify that a calendar exists for the scenario year.
    3. If it does not exist, create the calendar for that year (copy from the previous year and adjust holidays).
    4. Return to the Scenario Card and choose Create Simulations again.

    Simulation results show zero amounts¶

    Symptom¶

    After running Create Simulations, all cost amounts show 0.00.

    Cause¶

    • Employees do not have the Calculate Payroll field enabled.
    • No perception schemes are assigned to the employees.
    • The labor agreement specified in the scenario does not have a valid salary table for the scenario date.

    Resolution¶

    1. Verify that employees have the Calculate Payroll field enabled on their card.
    2. Check that employees have a perception scheme with salary concepts assigned.
    3. If you specified a labor agreement in the scenario, verify it has a salary table with amounts valid for the scenario date.
    4. Choose Create Simulations again.

    Comparison column (Forecast Monthly Cost -2) is empty¶

    Symptom¶

    In the Simulations page, the second scenario column shows no data.

    Cause¶

    • The second scenario filters (Fiscal Year Filter 2 and Scenario Filter 2) are not filled in.
    • The second scenario has not been executed and has no results.

    Resolution¶

    1. On the Simulations page, fill in Fiscal Year Filter 2 and Scenario Filter 2 with the second scenario data.
    2. If the column is still empty, open the second scenario and verify it has results (choose Simulation Overview).
    3. If it has no results, choose Create Simulations for that scenario.
    4. Return to the comparison page.

    Copy Scenario gives a duplicate error¶

    Symptom¶

    When you choose Copy Scenario, an error indicates that the code already exists.

    Cause¶

    A scenario with the code "[OriginalCode]-COPY" already exists. The copy function automatically generates this code.

    Resolution¶

    1. Open the Scenario List.
    2. Find the scenario with code "[OriginalCode]-COPY".
    3. Delete it or rename its code.
    4. Run Copy Scenario again.

    Salary revision percentage not applied to all employees¶

    Symptom¶

    Some employees do not reflect the salary revision percentage in the results.

    Cause¶

    The percentage is only applied to employees and categories whose action is Apply Forecast. If a category or employee has a different action (Do Not Apply, Discard, etc.), the raise does not apply.

    Resolution¶

    1. Open Scenario Config. Categories and verify that the desired categories have the action Apply Forecast.
    2. Check Scenario Config. Employees for individual exceptions.
    3. Choose Create Simulations again.
